# HH AutoApply Bot 🤖

[![Telegram](https://img.shields.io/badge/Telegram-Bot-blue?logo=telegram)](https://t.me/BotFather)
[![HH.ru](https://img.shields.io/badge/HH.ru-API-red)](https://dev.hh.ru/)
[![Yandex Cloud](https://img.shields.io/badge/Yandex-Cloud-orange)](https://cloud.yandex.ru/)

✨ Умный Telegram-бот для автоматизации поиска работы. Автоматически откликается на вакансии и генерирует персонализированные сопроводительные письма с помощью нейросети Yandex GPT.

## 🌟 Возможности

- 🔍 **Умный поиск вакансий** на hh.ru по заданным критериям
- ⚡ **Автоотклики** на подходящие вакансии (только без тестов)
- 🤖 **Генерация сопроводительных писем** с помощью Yandex GPT
- 💰 **Бесплатное использование** в пределах гранта Yandex.Cloud
- 👤 **Простой интерфейс** прямо в Telegram
- 📊 **Статистика откликов** и история отправленных заявок
- ⚠️ **Автоматическое пропускание вакансий с тестами** - бот откликается только на вакансии, где не требуется прохождение тестового задания

## 🚀 Быстрый старт

### 📋 Предварительные требования

1. **Yandex.Cloud**
   - 📧 Зарегистрируйтесь на [Yandex.Cloud](https://cloud.yandex.ru/)
   - 💳 Активируйте грант 4000₽ в [разделе Биллинг](https://center.yandex.cloud/billing/accounts/)

2. **HH.ru API**
   - 👨‍💼 Зарегистрируйтесь на [dev.hh.ru](https://dev.hh.ru/)
   - 📱 Создайте приложение в [разделе "Мои приложения"](https://dev.hh.ru/admin)

### 🔑 Настройка приложения HH.ru

При создании приложения укажите:

| Поле | Значение |
|------|----------|
| **Название** | `TelegramBotAutoApply` |
| **Callback URL** | `http://localhost:8000/callback` |
| **Права доступа** | ✅ Доступ к резюме<br>✅ Доступ к откликам |

Приложение будет на модерации примерно 2 дня

### 🔐 Получение токенов авторизации

#### Шаг 1: Получение authorization_code

Откройте в браузере ссылку:
```
https://hh.ru/oauth/authorize?response_type=code&client_id=ВАШ_CLIENT_ID&redirect_uri=http://localhost:8000/callback
```

#### Шаг 2: Обмен code на токены

```bash
curl -X POST https://hh.ru/oauth/token \
     -d "grant_type=authorization_code" \
     -d "client_id=ВАШ_CLIENT_ID" \
     -d "client_secret=ВАШ_CLIENT_SECRET" \
     -d "code=ПОЛУЧЕННЫЙ_CODE" \
     -d "redirect_uri=http://localhost:8000/callback"
```

**Ответ:**
```json
{
  "access_token": "xxxx",
  "refresh_token": "yyyy", 
  "token_type": "bearer",
  "expires_in": 1209600
}
```

## ⚙️ Установка и настройка

### 1. Клонирование репозитория

```bash
git clone https://github.com/ваш-username/hh_autoapply_bot.git
cd hh_autoapply_bot
```

### 2. Установка зависимостей

```bash
pip install aiogram httpx yandex-cloud-ml-sdk
```

### 3. Настройка конфигурации

Отредактируйте файл `bot.py` и замените значения в разделе конфигурации:

```python
# ==== Конфигурация ====
REAL_NAME = "Ваше Реальное Имя"  # Замените на ваше ФИО
TELEGRAM_TOKEN = "ваш_telegram_bot_token"
ACCESS_TOKEN = "ваш_hh_access_token"
RESUME_ID = "ваш_resume_id"
YANDEX_API_KEY = "ваш_yandex_api_key"
FOLDER_ID = "ваш_yandex_folder_id"
# ======================
```

### 4. Получение необходимых данных

#### 🤖 Telegram Bot Token
- Напишите [@BotFather](https://t.me/BotFather)
- Создайте нового бота командой `/newbot`
- Скопируйте полученный токен

#### 👤 Real Name
- Укажите ваше реальное ФИО, которое будет использоваться в сопроводительных письмах

#### 📄 Resume ID
Получите ID вашего резюме:
```bash
curl -H "Authorization: Bearer ACCESS_TOKEN" https://api.hh.ru/resumes/mine
```

#### 🔑 Yandex.Cloud настройка

**FOLDER_ID:**
- Перейдите в [консоль Yandex.Cloud](https://console.yandex.cloud/folders/)
- Скопируйте идентификатор папки

**API-ключ:**
- Перейдите в [сервисный аккаунт](https://console.yandex.cloud/iam/service-accounts)
- Создайте новый сервисный аккаунт или используйте существующий
- Создайте API-ключ для этого аккаунта

## 🎯 Использование бота

### Запуск бота

```bash
python main_bot.py
```

### Команды бота

| Команда | Описание | Пример |
|---------|----------|---------|
| `/start` | Запуск бота и просмотр команд | `/start` |
| `/search <запрос>` | Поиск вакансий без отправки откликов | `/search Python разработчик` |
| `/autoapply <запрос>` | Запуск автоматических откликов | `/autoapply Data Scientist` |
| `/stop` | Остановка автооткликов | `/stop` |
| `/stats` | Просмотр статистики откликов | `/stats` |

### Пример работы

1. **Запустите бота:** `python bot.py`
2. **В Telegram найдите вашего бота**
3. **Отправьте команду:** `/autoapply Python разработчик`
4. **Бот начнет автоматически:** 
   - Искать новые вакансии каждые 5 минут
   - Отправлять отклики с персонализированными письмами
   - Сообщать о статусе каждого отклика

## ⚠️ Важные замечания

### Лимиты и ограничения
- **HH.ru API:** Соблюдайте [лимиты запросов](https://dev.hh.ru/admin)
- **Yandex GPT:** Бесплатный грант 4000₽ (~2000 запросов)
- **Telegram:** Ограничение на частоту сообщений

### Рекомендации по использованию
- ⏱️ **Паузы между откликами:** 15-30 секунд
- 🔍 **Интервал проверки новых вакансий:** 5 минут
- 📝 **Качество писем:** Регулярно проверяйте сгенерированные письма
- 🎯 **Специфичность запросов:** Используйте конкретные ключевые слова для лучших результатов

### Безопасность
- Никогда не публикуйте токены в открытом доступе
- Используйте бота в соответствии с [правилами HH.ru](https://dev.hh.ru/)
- Регулярно обновляйте токены доступа

## 🐛 Устранение неполадок

### Частые ошибки

| Ошибка | Решение |
|--------|---------|
| `❌ Ошибка отклика 400` | Проверьте корректность ACCESS_TOKEN и RESUME_ID |
| `Yandex GPT не доступен` | Проверьте YANDEX_API_KEY и FOLDER_ID |
| `Не удалось получить данные резюме` | Убедитесь, что RESUME_ID корректен |

### Логирование
Бот автоматически сохраняет логи в консоль. Для более детального логирования можно настроить уровень логирования в коде.
